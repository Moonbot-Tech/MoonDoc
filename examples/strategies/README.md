# Catalog of ready-made Moonbot strategy templates

This section collects basic strategy templates in the Moonbot import format (`##Begin_Strategy ... ##End_Strategy`, schema `FVersion=12`). The code block is copied to the clipboard and pasted into the terminal's **`Strategies`** window with `Ctrl+V`:

* a block with one strategy starts with the `##Begin_Strategy` line — one strategy is pasted;
* a block with several strategies starts with the `##MultiSelection` line — the terminal pastes all strategies of the block at once (this is also how it copies several selected strategies itself). Without this line, only the first strategy from a text with several strategies is pasted, and the rest silently disappear. To take one strategy from such a block, copy it from `##Begin_Strategy` to `##End_Strategy`.

> **Before launching on a real account.** All templates ship disabled (`Active=0` — this is how the terminal itself writes a disabled strategy; the words `YES`/`NO` in this line are not accepted by import) and with the Emulator checkbox (`EmulatorMode=YES`). This checkbox protects only the strategy itself. Before drawing a spike with the **Pencil**, turn on **Menu → Emulation mode** (in a client + kernel link — on the kernel): all running strategies see the drawn trades, and live ones will answer the drawing with real orders. After the experiment, re-download the charts ([chapter 08](../../concepts/08-testing-debugging-and-analytics.md)).
>
> Key links, `CustomEMA` / `SellByCustomEMA` formulas, strategy sessions and repeat shots work only with the [“Autotrading” Extension](https://moonbot.pro/moonbot-pro/modules/autotrading) module or in the terminal's global Emulation mode. At the end of each template is a **“Checking the result”** block: what access is needed, what to replace, what to start, and which event confirms that the mechanism works. Also consult the [algorithm selection guide](../../reference/strategy-selection-guide.md) and the [list of common setup traps](../../reference/silent-killers-and-traps.md).
