# Images

Files referenced by `README.md` and the statistics pages.

| File | What it is | How it is updated |
| :--- | :--- | :--- |
| `moonbot-logo-full.svg` | Moonbot logo for the repository header | manually |
| `terminal-hero.jpg` | Screenshot of the classic Moonbot terminal | manually |
| `moonterminal-main.png` | MoonTerminal with the English interface | manually, from [MoonTerminal](https://github.com/Moonbot-Tech/MoonTerminal/blob/4a8518efff95577fec14924ac5d0c2cee2aad723/assets/img/screenshot-main.png) |
| `stats-current-month.svg` | Chart of the current month's daily result from [stat.moonbot.pro](https://stat.moonbot.pro/) | automatically, by [`scripts/update_stats.py`](../scripts/README.md) |
| `featured-trade.jpg` | Screenshot of a trade from the public channel [@MoonBot_Profit](https://t.me/s/MoonBot_Profit) | downloaded by the script only if missing; replace manually to change the screenshot |

The logo and screenshots are Moonbot product materials; when using them outside this repository, credit the source [moonbot.pro](https://moonbot.pro).
